# Fixture selection

Select all beside the group tabs reselects every fixture in the active group, replacing a partial/mixed selection. Group-tab clicks also select their group. Shift-click toggles individual members. Unverified entries may be selected for inspection but remain physically disabled.

Shared engine/MCP commands: `lights_selection_group` with `{group: "grid"}` or another group ID; `all` selects all enabled fixtures. `lights_selection_set` accepts `ids` and optional `group`; without `group` the previous group is kept only while every ID is still in it, so an empty selection clears the group. Clicking empty space (3D view, chip row, group grid background) selects none and leaves the group too, so the fixture buttons under the stage close. They list the chosen group's members (plus extra picks); with no group they list only the selected fixtures, and with nothing selected the strip is hidden. Runtime `selection` contains IDs, group and revision, which the UI follows. Selection is transient and does not change fixture attributes or saved shows.
