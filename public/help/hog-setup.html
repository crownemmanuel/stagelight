From the Mac
to the stage.

The exact Hog 4 setup that worked in our rehearsal. Keep this with the show computer.

1. Connect to FixtureNet

Connect the Mac’s Ethernet adapter to the Hog’s FixtureNet network. HogNet is the separate console-control network; it is not the Art-Net destination.

On the Hog, open Setup → Network → Processor 1 → Settings → FixtureNet and inspect the enabled interface and IP address. On versions with a separate Control Panel → FixtureNet page, inspect that page too. Our FixtureNet destination is 10.0.0.1. Do not overwrite a working network configuration.

On the Mac, the working Ethernet address was 10.0.0.50, mask 255.0.0.0, interface en12. Give each device a different address in the same subnet. Match the actual Hog netmask; the console’s mask was not captured in our screenshots. The interface name can change when adapters change.

ping -c 3 10.0.0.1 succeeded with 3/3 replies, averaging 0.585 ms. Ping proves IP reachability, not Art-Net reception. Our ArtPoll received no reply, but DMX control subsequently worked.

2. Route incoming Art-Net to Hog universes

Open Setup → Network → Processor 1 → Settings → Input (sometimes labelled Art-Net Input). Click Add Mapping. For the backlights, use universe range 3 through 3; for the six Rogue heads add 4 through 5. Check each row, then press Apply → OK.

This was the missing step in our first tests: the input mapping table was empty. Red DMX cells alone did not make Art-Net work. Hog universe numbers and incoming Art-Net addresses are different concepts; this show uses the mapping above.

Do not map a Hog universe’s Art-Net input and output to the same Art-Net subnet/universe. Inspect the Output tab before adding a new input route.

3. Hand only the intended DMX channels to Art-Net

Open Setup → DMX. Select Processor 1 and the required universe. Highlight the desired address cells and press Set to Art-Net Input. The values become red.

Do not select an entire universe by default. Art-Net contains a contiguous DMX frame, and this app sends zero in unused slots. Any other address handed to Art-Net can therefore be overridden to zero. If an entire universe was yielded during rehearsal, return the unrelated channels to HogNet control before using it in a show.

4. Verify a fixture, then expand

In this app, start in Preview. Open Connection to check the source address, destination, and universe map. Physical output starts only after you explicitly arm it; restarting the app does not re-arm it.

For fixture 402 at Hog 3:8, green is: dimmer (8) 255, red (9) 0, green (10) 255, blue (11) 0, white (12) 0, zoom (13) 127, reset (14) 0. Watch the red numbers in the Hog’s DMX window as well as the fixture. Raw DMX ranges from 0 to 255; 100 means roughly 39%, not full.

We verified green → purple → yellow, fades, a slow strobe, and a one-minute chase on all eight backlights. We also verified motion and open-shutter intensity on all six Rogue heads. The photo-look used Rogue coarse pan about 125 and tilt 144. Those are rehearsal coordinates, not calibrated stage angles.

Some backlights are double-patched on Universe 7. This app uses their verified Universe 3 patch. The six Rogue IDs’ exact physical left/right order remains unverified. MH7 and generic fixtures are only visual placeholders until their exact model, mode, address, and mapping are established.

What each personality controls

COLORado, relative channels 1–7: dimmer, red, green, blue, white, zoom, zoom control. Zoom control stays 0 (no reset).

Rogue R3, relative channels 1–16: pan, pan fine, tilt, tilt fine, pan/tilt speed, dimmer, shutter, color wheel, gobo, prism 1, prism 1 rotation, prism 2, prism 2 rotation, frost, focus, control. Shutter 0 closes; 255 opens. Control stays 0: it includes reset and lamp commands. Blackout closes the shutter and reduces the dimmer while preserving the current position. It does not strike or extinguish the discharge lamp.

5. Return control to the Hog

  1. Stop the effect and black out from the app. Disarm physical output.
  2. In Hog’s DMX window select the same channel ranges and choose Set to HogNet Input.
  3. Bring up a known Hog look and verify response. Keep the input mappings for next time if desired.

Stopping packets does not reliably hand control back. Rehearse sender loss, app restart, and the manual handback before a live show. This first version has no automatic redundant sender or guaranteed console takeover.

If nothing responds

  1. Check cable, adapter address and destination. Check that HogNet and FixtureNet use separate networks.
  2. Confirm the Input mapping exists and was applied.
  3. Confirm the correct processor/universe and red address cells.
  4. Check the app’s output is armed, master is above zero, and blackout is off.
  5. Watch the Hog’s DMX values. If they change but the fixture does not, inspect its physical mode, address, shutter/dimmer and lamp state.
  6. If UDP port 6454 is busy, close the earlier test sender. Run only one sender for this app’s output.

The connection panel separates interface presence and packet-send errors from receiver confirmation. “Sending” is never presented as proof that the Hog received a packet.
